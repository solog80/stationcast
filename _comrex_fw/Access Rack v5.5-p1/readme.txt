INSTALLING ACCESS AND BRIC-LINK FIRMWARE 

Follow these instructions exactly to avoid any potential damage and/or issues.
*********************************************************************************************
*********************************************************************************************

Once you've downloaded the update .zip file from our website (which you must have, if you're reading this...) you will need to extract the entire contents of the file before proceeding. 

To extract the contents of the .zip, right-click on the .zip file and select "Extract All".
Follow the on-screen prompts until the process is complete. 

Make sure that you use the extracted files for the remainder of these instructions.

To update your ACCESS or BRIC-Link (device), run the Device Manager application on a Windows PC or MAC that is connected to the same wired Ethernet network as your device.

You can then click the "Scan for Devices" button in the Device Manager window. The device should appear in the list on the left-hand side of the window.

Click the device in the list that you want to update, then click the "Upload Firmware" button in the right-hand part of the Device Manager window.

A file browser window should appear - use that window to navigate to the folder that was created when you extracted the .zip file's contents. 

Select the [exact_filename_may_vary].upd file and click the "Open" button.

A status bar will appear at the bottom of the window, right below the Status text area, indicating the firmware update process.

When the update is complete, the unit will reboot and the update is complete.
